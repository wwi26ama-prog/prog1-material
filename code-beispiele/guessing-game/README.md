# Zahlenratespiel

In diesem Verzeichnis wird das Guessing-Game aus der Vorlesung stückweise entwickelt.
Es werden mehrere aufeinander aufbauende Versionen gezeigt, die verschiedene
Aspekte verbessern und dabei Programmierkonzepte einführen.

Als Vorschlag für eine letzte Ausbaustufe liest [07-settings](examples/07-settings/)
die Anzahl der Versuche und den Zahlenbereich aus einer Textdatei.
