# Zahlenratespiel - Mehrere Versuche

Die Datei `main.go` enthält eine Variante, bei der die Überprüfung der
Benutzereingabe in eine Funktion ausgelagert worden ist.
Außerdem gibt es einen Test, der diese Funktionalität überprüft.

## Erläuterungen

- Es gibt eine zusätzliche Funktion `checkGuess()`,
  die die Benutzereingabe überprüft und eine Rückmeldung gibt.
- Außerdem gibt es in einer separaten Datei `main_test.go` einen Test,
  der die Funktionalität überprüft.

## Beobachtungen:

- Am Spiel selbst hat sich nichts geändert, dieses Beispiel dient dazu,
  zu zeigen, wie man Code automatisiert testen kann.
