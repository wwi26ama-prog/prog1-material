# Zahlenratespiel - Mehrere Versuche

Die Datei `main.go` enthält eine verbesserte Version des Spiels,
bei der der Spieler bei falschem Raten eine Rückmeldung bekommt,
ob die Zahl zu groß oder zu klein war.

## Erläuterungen

- Die `if`-Anweisungen wurden erweitert, mit denen geprüft wird, ob die Eingabe richtig war.
- Es gibt weiterhin die Abfrage, ob die Zahl erraten wurde, darunter gibt es nun aber
  zwei weitere Fälle statt nur einem.
  
## Beobachtungen:

- Die Änderung ist auf den ersten Blick klein, hat aber eine große Wirkung auf die Spielbarkeit.
- Mit einer geeigneten Strateggie kann der Spieler nun die Zahl in wenigen Versuchen erraten.
- Wie viele Versuche braucht man im schlimmsten Fall, um die Zahl zu erraten?
